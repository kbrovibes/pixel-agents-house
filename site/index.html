For people who run a lot of Claude Code

Your Claude Code sessions,
living in your house.

Every live session becomes a pixel-art character with a chore. Edits mean cooking, Bash means mowing the lawn, reading means the den. Idle agents actually rest on the couch. Put it on a wall monitor and glance over.

What makes it different

A rebuild of the Pixel Agents idea for an always-on screen, not a sidebar.

1

Idle looks idle

The status pill and the animation always agree. A session waiting on you sits on a sofa or sips coffee on the porch. Eight quiet minutes and it naps in a bed. Ended sessions walk out the front door.

2

Chores that mean something

The tool the model is using picks the chore. Reads and searches head to the desk or the mailbox, edits go to the stove and workbench, Bash pushes the mower or takes out the trash, web searches end up on the couch with the remote.

3

A real floor plan

Two floors of an actual house, transcribed from the architect's drawing at two feet per tile. The upper floor only appears when the main floor fills up and someone climbs the stairs.

4

Full screen, any device

Exact-fit pixel scaling, a kiosk mode that hides the chrome, and a server that binds to your LAN so an iPad on the wifi can be the display.

5

Zero configuration

It tails the transcript files Claude Code already writes. No hooks, no tokens, no build step. npm install, npm start, open the URL.

6

Click anyone

Tap a character for its project, branch, current tool and file, last prompt, last reply, and a tool-count breakdown. Helpers spawned by a session show up as smaller characters.

Who does what

The server classifies what each session is doing; the client turns that into a chore and finds a free station in the house.

Run it at home

Node 18 or newer, and Claude Code writing transcripts to ~/.claude/projects (the default).

git clone https://github.com/kbrovibes/pixel-agents-house.git
cd pixel-agents-house
npm install
npm start
# → http://localhost:4321  and  http://<your-lan-ip>:4321 for any device on the wifi
# wall monitor: http://localhost:4321/?kiosk=1&labels=1  then press F

No sessions running? npm run demo simulates ten. Details, configuration and the floor-plan format are in the README.
